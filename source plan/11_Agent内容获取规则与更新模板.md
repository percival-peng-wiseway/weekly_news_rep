# 11 Agent 内容获取规则与更新模板

## 用途

这是后续 Agent 的执行说明。每次运行应先读 `00_总索引.md`、本文件和目标模块，再获取内容、核验、去重、追加并输出运行摘要。

## 核心来源

严格按目标模块列出的核心来源检索；优先官方原文、原始数据和法定披露。搜索引擎只用于定位页面，不作为来源。遇到付费墙时不得凭摘要补全细节。

## 内容获取规则

1. **限定任务窗口**：记录检索起止日期、模块、地区和技术范围。
2. **先查一手，再查媒体**：媒体用于发现与解释；结论尽量链接政策原文、监管文件、数据或公告。
3. **三日期制**：事件日、发布日期、获取日分别记录；未知就写“未知”。
4. **逐项核验数字**：容量、金额、价格、目标、工期须带单位、币种、口径和来源。
5. **识别状态动词**：proposed/announced/awarded/approved/financial close/FID/commissioned/COD 不得互换。
6. **去重**：按项目/政策固定ID、标题实体、事件日期和主事件合并转载；保留最早一手来源。
7. **冲突处理**：同时保留冲突说法，说明可能的日期/口径差异，不擅自选边。
8. **推断显式化**：用“Agent判断”单列，写出依据与不确定性；不可包装为事实。
9. **追加不覆盖**：新状态新增记录，并用 `supersedes` 关联旧记录。
10. **隐私与合规**：不保存登录凭证、个人敏感信息或受限全文；只做合规摘要与链接。

## 追踪字段

运行ID、模块、检索窗口、检索式、已检查来源、未检查来源、候选条数、纳入条数、去重条数、待核验条数、冲突条数、写入记录ID、执行时间、失败/限制、下次动作。

## 关键词

除目标模块关键词外，组合使用地区、技术和状态词，例如：`Australia battery financial close`、`NSW wind development approval`、`AEMC final determination storage`。不得只用“renewable energy news”进行宽泛抓取。

## 更新频率

遵循 `09_每日每周每季度订阅计划.md`。若来源未更新，记录“已检查，无变化”，不要生成虚假条目。失败任务下一批重试，并说明缺口。

## 可靠性判断流程

```text
能否找到原始文件/数据？
├─ 能：核对日期、状态、数字和适用范围 → A/B
└─ 不能：是否有两个相互独立的可靠来源？
   ├─ 有：标为B/C，并保留“未找到一手来源”
   └─ 无：标为C/D和“待核验”，不得进入关键结论
```

独立来源不包括转载同一篇稿件的多个网站，也不包括同一机构的新闻稿和社交帖。

## 建议输出格式

默认先输出简洁运行报告，再把符合条件的单条记录追加到对应模块。不要重写整个文件；不要删除历史记录；不要把大段网页原文复制进文档。

## 质量检查清单

- [ ] 已读总索引、本规则和目标模块
- [ ] 每条均有事件日/发布日期/获取日
- [ ] 重大数字有单位和口径
- [ ] 项目与政策阶段没有夸大
- [ ] 至少一个原始链接，或明确标记待核验
- [ ] 事实、观点和Agent判断已分离
- [ ] 重复稿件已合并
- [ ] 冲突与访问限制已披露
- [ ] 新记录使用唯一ID；状态更新有 supersedes
- [ ] 文件编码为UTF-8，链接可访问，Markdown结构完整

## 更新日志

本规范变更需说明日期、原因、影响模块和是否需要迁移旧记录。
