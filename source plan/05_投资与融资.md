# 05 投资与融资

## 用途

观察资本流向、融资可得性和项目经济性，识别哪些技术与项目已从“有政策支持”走向“可融资、可建设”。

## 核心来源

- [CEFC投资组合](https://www.cefc.com.au/where-we-invest/) 与年报。
- [ARENA资金机会与项目](https://arena.gov.au/funding/)。
- CIS及州级承购/拍卖结果。
- ASX公告、公司财报、债券/贷款文件、收购方与卖方公告。
- Reuters、AFR等交易报道；行业数据库仅作补充。

## 追踪字段

交易ID、公告/完成日、资产/公司、买卖方、融资方、交易类型、权益比例、金额与币种、企业价值、债务/股权、利率/期限、资本开支、每MW/每MWh成本、PPA对手方/价格/期限/指数化、政府支持、CIS/ARENA/CEFC金额、估值倍数、财务关闭、附带条件、外资审批、减值、退出、来源、保密/未披露项。

## 关键词

`project finance`、`financial close`、`debt facility`、`equity investment`、`refinancing`、`green bond`、`PPA`、`tolling agreement`、`revenue swap`、`CIS agreement`、`acquisition`、`divestment`、`farm-down`、`impairment`、`insolvency`、`capital expenditure`、`cost overrun`、`FIRB`。

## 更新频率

- 每日/每周：重大融资、并购、PPA、减值和破产事件。
- 每月：融资事件及资本流向汇总。
- 每季度：CEFC/ARENA/行业投资报告、技术和州别趋势。
- 年度：财报、资产组合、WACC/利率环境与建设成本复盘。

## 可靠性判断

审计财报、ASX公告和正式融资文件为 A；交易双方一致公告为 A/B；单方新闻稿和未披露商业条款为 B/C；媒体引用匿名消息为 C/D。不得把“项目总投资”“股权投资”“贷款额度”“政府补助”相加后称作同一融资额。

## 建议输出格式

```markdown
### [FIN-YYYYMMDD-01] 交易/融资名称
- 资产与技术：
- 交易类型与状态：宣布 / 签约 / 有条件 / 完成 / 终止
- 各方角色：
- 金额、币种与口径：
- 债务/股权/补助/承购结构：
- 关键条件与期限：
- 对行业的信号：
- 可比指标：AUD/MW、AUD/MWh（仅在可比时）
- 一手来源及交叉来源：
- 未披露/待核验：
```

## 更新日志

交易从宣布到完成分别记录；若金额不公开，写“未披露”，不得估算后伪装为事实。
