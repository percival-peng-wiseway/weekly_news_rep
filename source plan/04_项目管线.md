# 04 项目管线

## 用途

追踪太阳能、风电、储能、输电、氢能及工业脱碳项目从早期宣布到商业运行的真实进度，避免把“规划容量”误当成“确定投产”。

## 核心来源

- 州规划/环境审批门户、EPBC 公示、REZ实施机构。
- AEMO发电信息、连接与规划资料；网络服务商项目页面。
- CIS/州级招标结果、ARENA/CEFC项目页。
- ASX法定公告、开发商财报和融资公告。
- RenewEconomy、pv magazine Australia、Reuters、AFR用于发现线索。

## 阶段字典

`传闻/概念` → `公开宣布` → `土地/选址` → `规划/环境评估` → `获批` → `并网申请` → `连接协议` → `承购/PPA` → `融资完成` → `FID` → `开工` → `机械完工` → `首次发电/充放电` → `注册/调试` → `COD/商业运行` → `运营/扩建/退役`

## 追踪字段

项目ID、名称、别名、开发商/业主、州与坐标、REZ、技术、MW、MWh、时长、阶段、阶段日期、土地、环评、规划许可、EPBC、并网申请/协议、PPA/承购、CIS状态、FID、融资、EPC、OEM、开工、预计/实际COD、资本开支、就业、社区利益、原住民协议、延误/取消原因、来源、最后核验日。

## 关键词

`development application`、`environmental impact statement`、`EPBC referral`、`connection application`、`connection agreement`、`generator performance standards`、`PPA`、`offtake`、`financial close`、`final investment decision`、`notice to proceed`、`construction commenced`、`first energisation`、`registration`、`commercial operations date`、`delay`、`impairment`、`withdrawn`。

## 更新频率

- 每日：重大 FID、融资完成、开工、取消、COD。
- 每周：项目新闻、审批、并网、招标与承购状态。
- 每月：所有活跃项目“最后核验日”轮询；高风险项目更频繁。
- 每季度：按州、技术、阶段汇总 MW/MWh，注明去重逻辑。

## 可靠性判断

审批决定、AEMO/网络文件、法定公告为 A；融资方或承购方正式公告为 A/B；开发商新闻稿为 C，特别是预计工期和投资额；媒体报道为线索。项目容量出现 AC/DC、名义/可用、功率/能量差异时必须保留原口径。


## 更新日志

同一项目保持固定项目 ID；所有更名、转售和分期项目维护别名及父子关系。
